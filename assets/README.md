# Company assets

`alomato-icon.png` is the original 128 × 128 PNG navigation icon embedded in [Alomato’s website](https://swaidathimannil.github.io/alomato/), extracted without modification from [`swaidathimannil/alomato/index.html`](https://github.com/swaidathimannil/alomato/blob/main/index.html).

It is stored locally so the company card does not depend on an external image request. The card displays the complete icon at 64 × 64 CSS pixels. Its empty alt text avoids repeating the adjacent “Alomato” heading for screen readers. The personal site’s favicons remain unchanged.
