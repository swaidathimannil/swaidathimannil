# Website upload workspace

This branch is prepared for the original website HTML and logo. `index.html` is currently a temporary placeholder, not the finished site.

## Add your files on GitHub

Keep all uploads and edits on **`arena/86c2c365-swaidathimannil`** so they can be picked up in the same Arena session.

1. [Open index.html in GitHub’s editor](https://github.com/swaidathimannil/swaidathimannil/edit/arena/86c2c365-swaidathimannil/index.html).
2. Select all of the placeholder content and replace it with your complete HTML. Commit directly to this branch.
3. [Open the branch](https://github.com/swaidathimannil/swaidathimannil/tree/arena/86c2c365-swaidathimannil), choose **Add file → Upload files**, and upload the logo as **`photo.jpg`** in the repository root. Include any other images, stylesheets, scripts, or fonts referenced by your HTML, preserving their relative paths.
4. Commit the uploads directly to the same branch, then return to Arena and say **“Files are on GitHub.”**

If you already have `index.html` as a file, you can upload it through **Add file → Upload files** instead of pasting its contents.

## Next steps

Once the source files are available, the site can be checked, obsolete assets removed, and the logo converted into ICO, SVG, PNG, Apple touch, and Android icon assets with the appropriate HTML references. No final favicons have been generated yet.

Pushing this branch does not publish the website or replace `main`. No deployment configuration has been added.
